# AI 应用开发岗位 - 简历项目条目

## 项目名称

**RAG 增强的 AI 全栈应用生成平台**

## 技术栈

**后端：** Java 21、Spring Boot 3、LangChain4j、Reactor/SSE、MyBatis-Flex、MySQL、Redis、Flyway、DashScope Embedding、腾讯云 COS

**前端：** Vue 3、TypeScript、Vite、Ant Design Vue、Pinia、Monaco Editor

**AI 与工程能力：** Tool Calling、RAG、SSE 流式输出、Prompt 安全护轨、任务持久化与恢复、自动构建修复、RBAC

## 项目介绍

面向非技术用户的 AI 全栈应用生成平台。用户输入自然语言需求后，系统自动完成需求规划、代码生成、结构化流式预览、构建修复和版本管理，将需求转化为可运行应用。平台支持应用级 RAG，检索历史需求和项目代码辅助增量修改，并通过托管数据模型、通用 CRUD API 与前端运行时 SDK，使生成结果从静态页面扩展为具备数据持久化、用户登录和权限控制能力的应用。

## 主要工作

- 重构 AI 代码生成链路：基于 LangChain4j Tool Calling 拆分创建与修改模式，创建阶段只开放文件写入和结束工具，修改阶段开放目录读取、文件读写、修改和删除工具，并解析流式工具调用参数，生成文件级增量事件后经 SSE 实时同步到前端目录和编辑器。
- 实现应用级 RAG：对源码与历史对话执行重叠切片、SHA-256 去重和持久化，采用关键词召回与可选 Embedding 语义召回、RRF 融合排序，将 Top 6 相关片段注入生成上下文；按应用 ID 隔离知识库，Embedding 异常时自动降级，不阻断主生成链路。
- 建设可恢复的流式任务系统：将生成任务、步骤、文件、进度和错误状态持久化，后端主动订阅模型流并通过 SSE 向前端转发，支持断线重连、刷新恢复、中止和继续，解决浏览器连接中断导致生成状态和结果丢失的问题。
- 形成“生成 - 验证 - 修复”闭环：对 Vue 项目执行依赖与构建检查，将构建日志反馈给 AI，最多进行 3 轮自动修改和复检；同时提供自动版本快照、任意版本 Diff、单文件恢复和整版本回滚，降低 AI 修改代码的不可控风险。
- 扩展托管数据运行时：支持 AI 规划数据模型，提供模型发布、通用 CRUD 和分页查询、应用用户登录与 RBAC，并向生成项目注入前端运行时 SDK，使生成应用能够安全访问持久化数据。
- 完善开发工作区与安全边界：使用 Monaco Editor、完整目录树和可拖动分栏展示生成代码，集成 Console、Network、Build 调试信息；统一校验文件相对路径、保护目录、大小和数量限制，并通过 iframe sandbox 隔离生成页面与主站运行环境。

## 面试口径

建议说明项目是在已有 AI 代码生成基线项目上完成产品化重构与功能增强，重点独立建设 RAG、生成任务可靠性、结构化代码流、自动修复、版本系统和托管数据运行时，而不是声称从 0 到 1 开发全部平台。
